The existing ABI still rejects model/character/GPU operations outside implemented core paths. F4 does not advertise MOC3 as a public SDK capability. `ARS_BUILD_MOC3_F4=OFF` requires both existing private D3D11 path and runtime components when enabled. A separate product bridge is linked from private core objects; the existing F2/F3 bridge remains a separate target.

## Ownership, identity and budgets

One simulation/render owner owns the native consumer, authorized source, pending core stage, evaluator, atlas residency and GPU query transaction. Copying a candidate into caller-owned bounded scalar storage preserves the existing stage lifetime and final authorization fence. Source tokens stay native and never appear in API responses/logs. A public frame carries session/run/core/snapshot/frame/device/target epoch identity; core generation is distinct from MOC snapshot generation. Disabled physics and missing controls have explicit behavior labels.

The product bridge retains two completed image slots and bounded private trace/timing records. Python consumes a slot before submitting another command; it copies metadata and bytes before publication. No background native producer overwrites a slot during that copy. Native frame cap 10,000 per worker; at most 32 mapped controls; one pending core candidate and one GPU transaction. Existing atlas/target/staging budgets and conservative 1536 MiB combined peak commit acceptance remain unchanged. A prepared source frame consumed or rejected by core follows existing replay/epoch semantics; the adapter does not roll back sequence numbers or mint replacement tokens to bypass rejection.

The first local proof uses bounded driven/released manual inputs into linked Physics3, not motions/expressions/idle orchestration or arbitrary-user import. Persistent external interactive control leases, whole-package live replacement and 30-minute hardware quality-tier acceptance need their own contracts. F4 whole product/activation stays HOLD until the remaining ledger is satisfied and an explicit activation decision exists.
