# F3 linked Physics3 execution contract

User authorized continuing F3 after rechecking and committing F2. Scope is a private, default-OFF, independently implemented Physics3 adapter feeding the same admitted package, evaluator and D3D11 host target. No official SDK is used. This document freezes the first slice before code. A synthetic viewer spring cannot satisfy these requirements.

The [official Physics3 format](https://github.com/Live2D/CubismSpecs/blob/master/FileFormats/physics3.json.md) describes input/output bindings, normalization, external forces and particle properties. It does not provide an independent animation reference. This adapter declares its own bounded deterministic integration policy; author/Cubism behavior equivalence remains HOLD until reference traces exist.

## Explicit integration policy

Use the model's actual minimum/default/maximum for piecewise normalization into each chain's Position or Angle range. Reflect negates the normalized source. Weighted X/Y inputs translate the root; weighted Angle rotates gravity. Manual values never bypass model ranges. Gravity JSON Y is mapped to the particle coordinate convention (positive Y along the default chain); wind remains expressed in particle coordinates. The declared independent particle rule uses bounded delayed semi-implicit motion, the file's Mobility/Delay/Acceleration and the Radius constraint; output X/Y is the selected segment displacement and Angle is atan2(segment.x, segment.y) in degrees. Reflect negates output, Scale applies, Weight blends toward it, then native parameter ranges clamp. No synthetic hair-specific IDs, learned private gains or measured thresholds are compiled into code.

Initial positions come from the linked file. Root translations apply relative to the declared root position. Non-root particles preserve the parent-child Radius after each integration step. A zero delay freezes local inertial integration while parent motion still applies the length constraint. All state values must stay finite; failed preparation does not mutate the accepted state. Native model parameters of constant range stay constant.

Limits: Physics3 1 MiB; at most 128 chains, 2048 total particles and 8192 total input/output bindings; at most 4096 native parameters; finite scalar absolute bound 1e6, normalization span at most 2e4, coordinates/radius at most 1e4; weights 0..100, mobility/delay 0..1, acceleration 0..100. Meta counts must match actual arrays. Fixed step is 16,666,667 ns; timestamp nonnegative int, maximum 8 steps including backlog; no silent time drop. The source Meta.Fps is validated when present but does not override this independent 60 Hz host policy. Native bridge retains F2 atlas residency, ownership and 1536 MiB combined peak acceptance unchanged. Public arbitrary-input safety, continuous product session, motions/expressions/idle arbitration and public activation remain outside this slice.

Delivery records design/build/local proof separately. If the private input requires an unrepresented feature or outputs do not affect actual geometry/pixels, preserve the failing packet and report the exact HOLD; do not substitute diagnostic springs or loosen thresholds. D06/D08 physical loss, authored fidelity and baseline gate statuses remain separate.

Format refinement before acceptance: normalization may be constant or have its default at an endpoint (`Minimum <= Default <= Maximum`). The official schema does not require a strict positive span. Constant normalization maps to its declared default; an inverted range still rejects. The first private parse exposed this over-restrictive admission assumption. Generated constant/endpoint tests are added alongside the inverted-range rejection; no pixel or physics-response oracle changes.
