## FINAL_ONLY_AUDIT instead of ongoing gate bureaucracy

GPT Auditor's reserved role is the final comprehensive assessment of a stable candidate: exact PR HEAD/changed files and owner custody, source and threat boundary, ancestry, material drift, negative test oracle correctness, raw CI and host/graphics/runtime constraints, vulnerabilities/P0/P1, rollback and compatibility with actual platform settings. Developer still performs ordinary SELF_CHECKS during development. An optional interim technical opinion is not a mandatory PRE-CLAIM gate.

## Independence classifications

- INDEPENDENT_REVIEW: independent qualified and demonstrably distinct actor; cannot be asserted for a one-account developer/auditor situation without proof.
- SEPARATE_GPT_REVIEW_LIMITED: methodologically separate examination, but provenance/identity limitations are disclosed.
- SELF_AUDIT: author or same assistant checks its implementation; this **is not** an independent PASS.
- **INDEPENDENCE_NOT_AVAILABLE**: recorded for this sole-account repo where no distinct GitHub reviewer participated.

Only the Human Owner can expressly accept a scoped **OWNER_ACCEPTED_SOLO_AUDIT_EXCEPTION**. The already accepted ARS-SOLO-OWNER-001 exception means an exact-source RED-first final technical-method review may be used without fabricating reviewer independence. It does not convert a relayed owner ChatGPT YES into a native GitHub APPROVED review or waive substantive security/GPU/OS tests, governance, source authorization or protection.

The Auditor reports actual PASS/HOLD/FAIL/UNKNOWN, scoped design versus production physical evidence, and any residual risk. A G00 design-freeze OWNER YES at a pinned SHA does not certify G01/G02/G07/G08/G10 or M1-D native GPU. New material changes require re-audit; final auditor cannot grant MERGE.
