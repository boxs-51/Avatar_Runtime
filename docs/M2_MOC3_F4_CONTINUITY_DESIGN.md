A two-second maximum input lease bounds abandoned held controls; it does not replace the native authorization lease or the final core fence. The timed soak measures this declared private workload only. G09's actual quality tiers, GPU allocation accounting and fallback remain required before G09 can close.

Clock policy: each presented update advances exactly six fixed physics steps, independently of the four-Hz presentation wall clock. This is a deliberately slowed fixed-clock continuity workload, not real-time catch-up physics or an FPS qualification. An interactive reset prepares rest state at the next simulation timestamp without changing the native authority wall clock. Input leases and test duration always use monotonic wall time. The bounded F4-A physics backlog checks remain unchanged.
